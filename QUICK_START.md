# Quick start

1. Install Node.js 22.5 or newer.
2. Run `npm install` in the project folder.
3. Run `npm run dev` and open the local Vite address shown in the terminal.

The development command starts both the React app and its local API. App data is saved to `resqlink.sqlite` in the project root. Create an account through the sign-up page to get started.

Run `npm run build` to create a production frontend build.
